📋 รายละเอียดทริป: "ม่อนปุยหมอก" จ.ตาก 17-18 ตุลา 69

( ทริปหารเฉลี่ย จัดไปกันเอง )
📅 16 ตุลา 69
  • 20.00 รวมตัวที่จุดขึ้นรถ พร้อมออกเดินทาง
📅 17 ตุลา 69
  • 06.00 ถึงอุทยานแม่เมย ทำธุระส่วนตัว เปลี่ยนชุดเตรียมลุย หาทานอาหารเช้า
  • 08.00 เริ่มเดินขึ้นม่อนปุยหมอก ( รับข้าวเที่ยง มื้อ1 และน้ำดื่ม )
  • 17.00 ช่วยกันทำอาหารเย็น มื้อที่ 2 ชาบู
📅 18 ตุลา 69
  • 06.00 ตื่นนอน และช่วยกันทำอาหารมื้อเช้า มื้อที่ 3 +กาแฟ โอวัลติน
  • 09.00 เริ่มทยอยเดินลงมา
  • 14.00 เดินทางกลับกรุงเทพ
  • 19.00 แวะกินข้าวที่ ตาก / นครสวรรค์ ถ้ายังกินไหว ( ดูแลตัวเอง )
  • 22.00-00.00 คาดว่าถึงกรุงเทพ

  • รถตู้วีไอพี 10 ที่นั่ง + น้ำมัน
  • ค่าเข้าอุทยาน-ค่ากางเต็นท์
  • ค่าลูกหาบกองกลาง
  • ค่าเจ้าหน้าที่นำทาง
  • ค่าอาหาร 3มื้อ ที่ระบุ
